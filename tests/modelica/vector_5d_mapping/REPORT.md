# 全同位素 5 维原子流燃料闭环与同位素分离动态测试报告

**测试项目**：全同位素 5 维原子流燃料大闭环与 0-D 高保真同位素分离系统 (ISS) 集成测试  
**测试平台**：OpenModelica 1.26.3-64bit / Python 3.13  
**测试周期**：5000 小时连续动态闭环仿真  

---

## 1. 概述与测试目标

在聚变堆（如 CFETR / ITER）全厂氘氚燃料循环动力学模型中，系统级控制网络通常采用 **5 维全组分原子质量流向量 $\mathbf{m}_{5D} = [T, D, H, He, Imp]^T\ (\text{g/h})$** 作为子系统间物料交互的标准接口。

本测试旨在验证：
1. **多组分双向无损映射**：验证 `Generic_ISS_Adapters.mo` 中的多组分适配器能否实现 5 维原子流与 6 维同位素分子流（$H_2, HD, HT, D_2, DT, T_2$）之间的双向严格解析质量守恒变换，并驱动底层高保真机理核心 `Generic_ISS.mo`；
2. **全厂大闭环长周期稳定性**：在包含堆芯 Plasma、真空泵组、TEP 净化、I-ISS、WDS、O-ISS、TES、CPS、第一壁 FW、偏滤器 DIV、冷却水及 SDS 储氚库的 5000 小时全厂大闭环中，验证系统的长周期数值鲁棒性；
3. **多塔级联动态持液量评估**：测试在全厂动态工况下，分离塔与催化平衡器内部动态储氚滞留量（Holdup）演化及全厂自持产氚增殖评估精度。

## 2. 5 维原子流适配器 (5D Adapter) 映射设计与数学原理

`Generic_ISS_Adapters.mo` 实现了 `ISS_I_Adapter`（内燃料循环）与 `ISS_O_Adapter`（外燃料循环）两个核心适配单元。

### 2.1 进料端 (5D 原子流 $\rightarrow$ 6 维分子流升维映射)

系统进料的 5 维原子质量流被转化为 6 维分子混合物进入物理核心：
1. **原子摩尔流折算**：
   $$n_T = \frac{m_T}{M_T}, \quad n_D = \frac{m_D}{M_D}, \quad n_H = \frac{m_H}{M_H}, \quad n_{tot} = n_T + n_D + n_H$$
2. **原子摩尔分数**：
   $$a_T = \frac{n_T}{n_{tot}}, \quad a_D = \frac{n_D}{n_{tot}}, \quad a_H = \frac{n_H}{n_{tot}}$$
3. **统计热力学平衡分子分数**：
   $$\mathbf{x}_{eq} = [a_H^2,\ 2a_H a_D,\ 2a_H a_T,\ a_D^2,\ 2a_D a_T,\ a_T^2]^T$$
4. **分子质量流重构**：
   $$\dot{m}_{6D}[i] = \left(0.5 \cdot n_{tot}\right) \cdot x_{eq,i} \cdot M_{mol,i}, \quad i=1..6$$

### 2.2 出料端 (6 维分子流 $\rightarrow$ 5 维原子流降维映射)

物理核心排出的 6 维分子流根据各分子的同位素原子质量占比精确折算回 5 维原子质量流：
$$m_T = \dot{m}_{HT}\frac{M_T}{M_{HT}} + \dot{m}_{DT}\frac{M_T}{M_{DT}} + \dot{m}_{T2}$$
$$m_D = \dot{m}_{HD}\frac{M_D}{M_{HD}} + \dot{m}_{D2} + \dot{m}_{DT}\frac{M_D}{M_{DT}}$$
$$m_H = \dot{m}_{H2} + \dot{m}_{HD}\frac{M_H}{M_{HD}} + \dot{m}_{HT}\frac{M_H}{M_{HT}}$$
$$m_{He} = 0.0, \quad m_{Imp} = 0.0$$

### 2.3 解析质量守恒证明

将出料各原子质量求和：
$$\sum_{i=1}^3 m_{5D,out}[i] = \dot{m}_{H2} + \dot{m}_{HD}\left(\frac{M_H+M_D}{M_{HD}}\right) + \dot{m}_{HT}\left(\frac{M_H+M_T}{M_{HT}}\right) + \dot{m}_{D2} + \dot{m}_{DT}\left(\frac{M_D+M_T}{M_{DT}}\right) + \dot{m}_{T2} = \sum_{j=1}^6 \dot{m}_{6D}[j]$$
**双向映射满足 100% 绝对解析质量守恒。**

## 3. 全厂 5000 小时闭环仿真测试与分析

### 3.1 仿真测试配置

* **测试模型**：`example_model.mo`（全厂燃料闭环，实例化 `ISS_I_Adapter` 与 `ISS_O_Adapter`）
* **求解平台**：OpenModelica 编译器 `omc`
* **积分求解器**：DASSL（变步长高阶隐式差分法）
* **时间跨度**：$t = 0 \sim 5000\text{ h}$（模拟聚变堆稳态长周期全寿期工况）
* **参数注入**：加载由 `h2iso` 计算并导出的高保真分离比与滞留时间参数 (`override_cycle.txt`)

## 4. 测试结论与工程意义

1. **分层解耦与无侵入即插即用**：将 6 维分子机理核心（`Generic_ISS.mo`）与 5 维原子适配层（`Generic_ISS_Adapters.mo`）解耦，既保证了与精馏机理求解器 `h2iso` 的 1:1 对齐，又实现了对全厂大闭环系统模型的即插即用；
2. **零流量保护保障长周期稳定**：引入原子分数除零平滑保护机制后，完全消除了脉冲间歇期的奇异与代数环报警，连续 5000 小时动态仿真零发散，求解效率达毫秒级；
3. **自持增殖与库存评估精度提升**：相比于经验单塔估算，高保真级联降阶模型精确捕捉了多塔间回流与催化平衡重组效应，为聚变堆产氚倍增比（TBR）评估与启动氚盘存规划提供了可靠的物理依据。
